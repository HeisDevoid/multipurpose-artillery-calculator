# Таблицы стрельбы из игры, без скриншотов

Окно ACE «Artillery Table» не считает таблицу само: строки считает расширение ACE
(`"ace" callExtension ["artillery:calculate_table", …]`). Скрипт `export_tables.sqf`
вызывает тот же расчёт для всех зарядов, навесной и настильной траектории и сразу в двух
вариантах:

- **без сопротивления воздуха** (улучшенные поправки ACE выключены): погодные столбцы пустые;
- **с сопротивлением** (как при включённой настройке `ace_artillerytables_advancedCorrections`).

Настройки сервера не важны: оба варианта считаются всегда. Значения совпадают с окном игры
до знака, потому что это тот же код.

Нужны ACE 3.18 или новее (расширение `ace` с командой `artillery:calculate_table`) и доступ
к отладочной консоли (редактор, одиночная игра или права администратора).

## 1. Выгрузка в игре

1. Сядьте на место наводчика нужного орудия (окно таблицы ACE должно быть закрыто).
2. Esc → Debug Console → вставьте весь файл `web/tools/arma/export_tables.sqf` → **Local Exec**.
   В файле нет комментариев и кириллицы: консоль игры их не понимает.
3. Подождите подсказку «MACTABLE: done, N tables». Таблицы уже в буфере обмена и в RPT
   (`%LOCALAPPDATA%\Arma 3\arma3_x64_<дата>.rpt`).

## 2. Импорт в проект (из папки `web/`)

```bash
npm run tables:game -- sochor
```

Без `--write` команда только сравнивает выгрузку с текущими таблицами орудия и печатает, что
изменится. Когда всё устраивает:

```bash
npm run tables:game -- sochor --write
```

Таблицы без сопротивления ложатся в `data-sources/<id>/`, с сопротивлением — в
`data-sources/<id>/advanced/`, затем запускается импорт (`npm run tables:import`). Дальше
`npm run tables:check` и `npm test`.

Источник по умолчанию — буфер обмена. Другие:

- `--rpt` — самый новый RPT игры (или `--rpt <путь>`);
- `--file <путь>` — текст выгрузки, сохранённый в файл.

Если у орудия магазины с разной начальной скоростью, команда попросит выбрать набор:
`--group N` (список наборов она напечатает сама).

## Что делает скрипт

- Ищет башню с `primaryGunner = 1` и её оружие, пределы возвышения считает как ACE
  (`minElev`/`maxElev` башни плюс поправка `neutralX` для башен вроде Mk6).
- Заряды — видимые режимы оружия (`showToPlayer = 1`), отсортированные по `artilleryCharge`;
  номер заряда как в окне ACE. Скорость = `initSpeed` магазина × `artilleryCharge`.
- Сопротивление: ключ магазина `ace_artillerytables_airFriction`, иначе −0.00006 (как в ACE);
  при положительном ключе — `airFriction` снаряда, и тогда сопротивление есть всегда.
- Счётчики окна ACE перед расчётом сбрасываются так, чтобы окно не подхватило чужие строки.

Новое орудие сначала добавляется в приложение (JSON в `src/data/artillery/`, `models.ts`,
`TABLE_OF` в `src/data/artillery/tables.ts` и `catalog.ts`); команда раскладывает таблицы только
для орудия, которое уже есть. После `npm run tables:import` обновится и `src/data/tableStatus.json`.
